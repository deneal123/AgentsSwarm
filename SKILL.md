# SKILL.md — Создание документов .tex в стиле научного отчёта

## Назначение

Навык помогает генерировать код LaTeX для оформления научно-технических материалов
(презентаций, отчётов, постеров) с точным позиционированием текста и графики.
Стиль соответствует реальным рабочим примерам: таблицы, рисунки, выноски, цветные
плашки, стрелки-указатели, колонтитулы и т.п.  
Основной упор — на воспроизведение визуальной структуры, аналогичной
приведённому образцу, но с использованием современных, стабильных пакетов,
где это возможно.

## Инструкция для ассистента

1. **Всегда начинай с полной преамбулы** на основе шаблона ниже.
2. Жёстко фиксируй размер страницы через `geometry`, используй `overlay`-режим
   у `tikzpicture` для фона и линий.
3. Для надписей и таблиц применяй **комбинацию** `picture`-окружения
   и команд `\put` – это даёт абсолютные координаты, как в образце.
   **Важно:** всегда задавай `\unitlength` перед `picture`, чтобы координаты
   были предсказуемыми.
4. Цвета задавай через `\definecolor`, шрифты – строго через команды
   `\usefont` внутри `\put`.
5. Рисунки вставляй с помощью `\includegraphics`, помещённого в `\put`.
6. **Нумерация страниц**: используй абсолютное позиционирование (например,
   `\put(656.05,-511.907){...}`), а не колонтитулы.
7. Если пользователь просит «современный синтаксис» – предлагай переход
   на LuaLaTeX/XeLaTeX, `fontspec`, `polyglossia`, но сохраняй логику
   абсолютного позиционирования.

## Обязательная структура (шаблон)

```latex
\documentclass{article}
\usepackage{amsmath}
\usepackage{color}
\usepackage[T1]{fontenc}
\usepackage[utf8]{inputenc}          % Вместо utf8x
\usepackage{tikz}
\usepackage{graphicx}                % Для \includegraphics
\usepackage[margin=0in,paperwidth=720pt,paperheight=540pt]{geometry}
\pagestyle{empty}

% Цвета
\definecolor{bg}{rgb}{1,1,1}
\definecolor{gray}{rgb}{0.537,0.537,0.537}
\definecolor{black}{rgb}{0,0,0}
\definecolor{yellow}{rgb}{1,1,0}

\begin{document}
% Страница 1
% 1. Фон
\begin{tikzpicture}[overlay,remember picture]
  \fill[bg] (current page.south west) rectangle (current page.north east);
\end{tikzpicture}

% 2. Основное содержимое через picture
\setlength{\unitlength}{1pt}         % Ключевая настройка!
\begin{picture}(0,0)
  % Заголовок
  \put(X,Y){\fontsize{18}{1}\usefont{T1}{uarial}{m}{n}\selectfont\color{black}Текст}
  % Таблица (строки и ячейки точно через \put)
  ...
\end{picture}

% 3. Линии таблицы поверх всего
\begin{tikzpicture}[overlay,remember picture]
  \draw[black,line width=1pt] (x1,y1) -- (x2,y2);
  ...
\end{tikzpicture}
```

Ключевые элементы и их синтаксис

1. Определение цветов

```latex
\definecolor{mycolor}{rgb}{R,G,B}     % значения 0..1
```

Используй в заполнении, тексте, линиях: \color{mycolor}.

2. Абсолютное позиционирование текста

```latex
\setlength{\unitlength}{1pt}
\begin{picture}(0,0)
  \put(Xpt, Ypt){\fontsize{size}{skip}\usefont{T1}{family}{series}{shape}\selectfont\color{color} текст}
\end{picture}
```

- координаты в пунктах (pt), начало отсчёта – левый верхний угол (положительный X вправо, положительный Y вверх) *
- семейства шрифтов: uarial (Arial), ptm (Times), cmr (Computer Modern) и т.д.
- В действительности в picture точка (0,0) по умолчанию – левый нижний угол, но в примере используются смещения. Для совместимости с образцом размещайте текст так, чтобы визуально соответствовать макету; при необходимости подбирайте координаты экспериментально.

3. Рисование линий и таблиц

Линии рисуются отдельным tikzpicture с overlay, после или до текста:

```latex
\begin{tikzpicture}[overlay,remember picture]
  \draw[black,line width=1pt] (x1,y1) -- (x2,y2);
  \draw[black,line width=1pt] (x1,y1) -- (x2,y2) -- (x3,y3); % ломаная
\end{tikzpicture}
```

Для стрелок используй \filldraw с заданием цикла из трёх точек, как в примере:

```latex
\draw[yellow,line width=0.5pt] (367.75pt, -99pt) -- (366.3256pt, -118.6368pt);
\filldraw[yellow] (366pt, -123.1251pt) -- (369.4262pt, -117.3578pt) --
  (369.4262pt, -117.3578pt) -- (363.442pt, -116.9237pt) -- cycle;
```

4. Вставка изображений

```latex
\put(Xpt, Ypt){cludegraphics[width=Wpt,height=Hpt]{latexImage_хеш.png}}
```

- Имена файлов лучше брать такими, как в образце, или задавать свои.
- Если изображение временно скрыто, используй окружение comment.

5. Формирование таблиц

Все ячейки – отдельные \put. Никаких tabular. Это даёт полный контроль.
Заголовки выравниваются по колонкам вручную.
Пример строки:

```latex
\put(30.875,-102.5176){\fontsize{10}{1}\usefont{T1}{uarial}{m}{n}\selectfont\color{black} Название}
\put(114.3125,-150.3301){\fontsize{10}{1}\usefont{T1}{ptm}{m}{n}\selectfont\color{black} 9941±2}
```

6. Нумерация страниц и колонтитулы

```latex
\put(X,Y){\fontsize{12}{1}\usefont{T1}{cmr}{m}{n}\selectfont\color{gray}1/11}
```

Актуальные рекомендации по современному LaTeX

Хотя приведённый шаблон работает в pdflatex, современная практика предлагает:

- Кодировка: \usepackage[utf8]{inputenc} вместо utf8x.
- Шрифты: если нужен точный Arial/Times без base-кодировок, переходи на LuaLaTeX/XeLaTeX:
  ```latex
  \usepackage{fontspec}
  \setmainfont{Times New Roman}
  \newfontfamily\arial{Arial}
  ```
  Тогда в тексте можно писать \arial текст.
· Позиционирование: вместо picture можно использовать tikz с remember picture, overlay и ноды с абсолютными координатами – код станет чище:
  ```latex
  \begin{tikzpicture}[overlay,remember picture]
    \node[anchor=north west, inner sep=0] at (Xpt, Ypt) {текст};
  \end{tikzpicture}
  ```
- Графика: все изображения хранить в подпапке и указывать путь в \graphicspath{{./img/}}.
- Условная компиляция: для скрытия частей документа использовать comment как в оригинале, либо средства \ifdefined.

Однако если цель – максимально точное соответствие уже готовому стилю,
придерживайся первого раздела (pdflatex + picture + \put).

Обзор современных пакетов для абсолютного позиционирования

Пакет Назначение Ключевые команды Примечания
picture + \put Классическое абсолютное позиционирование \put(x,y){...} Требует \unitlength; ограниченная графика
TikZ (с overlay) Мощное позиционирование и графика \node at (x,y) {...}; Рекомендуется для новых проектов
eso-pic Фоновые/наложенные изображения \AddToShipoutPictureFG Идеально для водяных знаков и логотипов
textpos Абсолютное размещение блоков \begin{textblock}{w}(x,y) Удобен для постеров; требует [absolute]
abspos Абсолютное позиционирование через «гробы» \abspos{x}{y}{anchor}{content} Современный, без двухпроходной компиляции

Частые сценарии использования

- Создание постера или слайда с жёсткой сеткой.
- Перенос готового макета из другой программы в LaTeX.
- Оформление планшета с результатами моделирования, где каждый показатель
  находится на строго определённом месте.
- PDF-отчёты с идентичным расположением элементов на каждой странице.

Примечания

- Все координаты можно вычислять относительно текущей страницы, если добавить
  remember picture и использовать (current page.north west) в tikz.
- Для отладки позиций полезно временно вставлять \usepackage{layout} и
  \layout или сетку из tikz.
- При использовании picture нулевого размера (0,0) начало координат
  реально находится в левом нижнем углу области рисования, но в примере
  видно смещение на несколько пт; не меняй этот стиль, если не требуется.
