# Isaac Mission Dispatch

**Isaac Mission Dispatch** — это облачный сервис для обмена данными между роботами на edge-уровне и облачными сервисами управления флотом.

Сервис позволяет fleet management-системе отправлять миссии нескольким роботам, отслеживать состояние роботов и выполнение заданий. Для связи используется протокол **VDA5050** поверх **MQTT**.

Mission Dispatch состоит из двух основных микросервисов:

- **Mission Database** — хранит состояние миссий, роботов и API-объектов, предоставляет REST API для создания, обновления и получения данных.
- **Mission Dispatch** — управляет коммуникацией с роботами, обрабатывает переходы состояний миссий и передаёт задания клиентам.

Миссия представляет собой последовательность задач для конкретного робота и транслируется в VDA5050-заказы. Для выполнения миссий робот должен использовать совместимый **Mission Client**. ROS 2 Mission Client доступен для ROS 2 Humble и Jazzy.

Важно: Mission Dispatch не решает задачи логистики флота, такие как распределение заданий, планирование маршрутов или предотвращение конфликтов между роботами. Он отвечает за надёжную доставку миссий, обмен состояниями и интеграцию роботов с системой управления флотом через VDA5050.

На текущий момент поддерживается только протокол **VDA5050**.

## Быстрый старт

1. *Положить файл переменных сред в папку docker/.env*
2. *Пример файла переменных сред в папке docker/.env.example*

```bash
make start     # Клонировать и запустить
```

## Если репозиторий уже склонирован:

```bash
make submodule-init
make up
```

make help
