# Isaac Mission Control

**Mission Control** — это легковесный менеджер флота, который координирует облачные сервисы Isaac и управляет их совместной работой.

При отправке заданий Mission Control формирует **дерево поведения** из необходимых задач. В процессе построения и выполнения задания он использует:

- карту занятости;
- **CSR-граф** карты занятости, предоставляемый **SWAGGER**;
- оптимальные маршруты в этом пространстве, рассчитываемые **cuOpt**.

Затем Mission Control задействует **Mission Dispatch**, чтобы выполнить дерево поведения через протокол **VDA5050** с помощью **Mission Client**.

Внутри NVIDIA Mission Control используется как инструмент разработки для небольшого флота автономных мобильных роботов (**AMR**): он помогает автоматизировать тестирование Isaac, доставку заданий и другие внутренние сценарии.

## Быстрый старт

1. *Положить файл переменных сред в папку docker/.env*
2. *Положить файлы конфигурации и occupency map в папку docker/config*

```bash
make start     # Клонировать и запустить
```

## Если репозиторий уже склонирован:

```bash
make submodule-init
make up
```
