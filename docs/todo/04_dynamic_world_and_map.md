# TODO: 04_dynamic_world_and_map

## Описание
Создание случайного, динамически генерируемого окружения (препятствия) для проверки поведения алгоритмов навигации.

## Задачи
- [ ] **Скрипт генерации препятствий**
  - В метод `setup_scene` Python-скрипта (см. Step 01) добавить вызов функции `add_random_obstacles(stage, num_obstacles)`.
  - Внутри функции реализовать цикл на `num_obstacles` итераций.
  - Настроить случайную генерацию координат (`x = random.uniform(-5, 5)`, `y = random.uniform(-5, 5)`).
- [ ] **Добавление примитивов в сцену (Stage)**
  - Задать путь `path = f"/World/Obstacle_{i}"`.
  - Сформировать геометрию: `cube = UsdGeom.Cube.Define(stage, path)`.
  - Использовать `AddTranslateOp().Set(Gf.Vec3d(x, y, 0.5))` для позиционирования.
  - Задать размер: `cube.GetSizeAttr().Set(0.5)`.
- [ ] **Физика и коллизии**
  - Подключить `Physics API` к препятствиям. Использовать `RigidPrim` или вручную добавить `UsdPhysics.CollisionAPI`.
  - Удостовериться, что сенсоры (лидары) Carter'ов детектируют коллизии лучами, чтобы Nav2 `obstacle_layer` их видел.
- [ ] **Генерация предварительной карты (Опционально / Hybrid-режим)**
  - Импортировать `omni.kit.occupancy_map` из расширений Isaac Sim.
  - Написать скрипт-команду для генерации базовой occupancy grid из геометрии `stage`.
  - Сохранить `.yaml` и `.pgm` в папку ресурсов для альтернативной подгрузки в `map_server`.
- [ ] **Интеграция с процессом запуска**
  - Поместить генератор в основной `app` симуляции.
  - Проверить через `RESET`, что физика сцены применяется корректно и кубы падают/стоят на месте.
