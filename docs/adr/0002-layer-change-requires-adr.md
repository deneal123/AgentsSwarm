# ADR-0002: Крупные изменения слоя требуют ADR

- Статус: Accepted
- Дата: 2026-04-23

## Контекст

Проект использует слоистую архитектуру и нуждается в прозрачных архитектурных решениях.

## Решение

Каждое крупное изменение любого слоя сопровождается новым ADR в `docs/adr/`:
- presentation,
- application,
- services,
- agents,
- repositories,
- infrastructure.

Крупным изменением считается как минимум одно из:
- изменение границ ответственности слоя,
- добавление нового доменного потока между слоями,
- смена контракта layer-to-layer взаимодействия,
- смена технологического механизма внутри слоя,
- изменение правил надежности/безопасности слоя.

## Последствия

- Архитектурные решения фиксируются до или одновременно с кодом.
- Ревью архитектуры становится воспроизводимым и аудитируемым.
