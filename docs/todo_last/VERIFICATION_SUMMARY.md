## ⚠️ Что Требует Расширения

### 1. Недостающие REST API Эндпоинты

#### `GET /api/v1/swarm/status` — Приоритет: ВЫСОКИЙ
- **Назначение:** Агрегированная информация о рое
- **Требуемые поля:** Статусы роботов, активные задачи, предупреждения
- **Компонент:** `api/v1/robots.py`
- **Сложность:** Средняя (требует агрегирования данных из Redis)
- **Предполагаемое время:** 2-3 часа
- **Код доступен в:** `IMPLEMENTATION_GUIDE.md`

#### `POST /api/v1/vision/analyze_robot` — Приоритет: ВЫСОКИЙ  
- **Назначение:** Анализ изображения робота через Triton + vLLM
- **Требуемые поля:** Детекции, анализ сцены, рекомендации
- **Компонент:** Новый `api/v1/vision.py`
- **Сложность:** Средняя-высокая (требует интеграции с Triton)
- **Предполагаемое время:** 3-4 часа
- **Код доступен в:** `IMPLEMENTATION_GUIDE.md`

#### Администрирование (3 эндпоинта) — Приоритет: СРЕДНИЙ
- `PUT /api/v1/admin/config` — обновление конфигурации
- `POST /api/v1/admin/models/deploy` — обновление моделей  
- `GET /api/v1/admin/users` — требует расширения (полный CRUD)
