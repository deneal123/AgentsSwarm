# Neo4j — Графовая база данных

## Роль

Neo4j хранит топологию среды, связи между объектами, историю взаимодействий агентов и семантические связи (например, зона A смежна зоне B).

---

## Модель данных

- Узлы: Robot, Zone, Object, Task, ChargingStation
- Связи: (Robot)-[:IN_ZONE]->(Zone), (Robot)-[:EXECUTED]->(Task), (Object)-[:LOCATED_IN]->(Zone)
- Атрибуты: позиции, временные метки, свойства объектов

---

## Примеры запросов

- Поиск ближайшей зарядной станции к роботу
- Поиск объектов заданного класса в радиусе
- Анализ истории взаимодействий для root-cause анализа

---

## Репликация и бэкап

- Регулярный экспорт графов и snapshot-резервные копии
- Репликация для обеспечения высокой доступности
