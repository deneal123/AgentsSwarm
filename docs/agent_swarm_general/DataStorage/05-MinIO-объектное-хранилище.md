# MinIO — Объектное хранилище

## Роль

MinIO служит S3-совместимым хранилищем для изображений, логов, версий моделей и артефактов обучения.

---

## Структура бакетов

- `raw-images` — необработанные кадры
- `processed` — результаты анализа (JSON + ссылки на маски)
- `models` — веса моделей с версионированием
- `logs` — архивные логи и дампы

---

## Политики хранения

- Версионирование объектов для отката
- Жёсткие политики доступа (bucket policies)
- Lifecycle rules: перемещение старых артефактов в холодное хранилище

---

## Интеграция

- Triton и vLLM подтягивают модели напрямую из MinIO
- Gateway передаёт ссылки на MinIO вместо отправки больших payloads по MQTT
