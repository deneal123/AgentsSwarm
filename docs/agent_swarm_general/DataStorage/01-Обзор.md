# Data Storage — Обзор

## Назначение

Подсистема хранения отвечает за долговременное хранение телеметрии, изображений, моделей, графовой информации и временных рядов, а также за быстрый доступ к оперативным данным.

---

## Компоненты

- InfluxDB — временные ряды (телеметрия, метрики)
- Neo4j — графовая БД для хранения топологии среды, связей объектов и историй взаимодействий
- Redis — кеш, feature store и pub/sub
- MinIO — объектное хранилище (кадры, логи, модели)
- PostgreSQL — реляционные данные (пользователи, задачи, инциденты)

---

## Политики хранения

- TTL для временных рядов (InfluxDB) и кэшей (Redis)
- Архивация старых артефактов в холодное хранилище (S3 Glacier или аналог)
- Версионирование моделей и метаданных в MinIO

---

## Интеграция

- API Gateway и Orchestrator читают/пишут данные через абстрактные репозитории
- batch-джобы для ETL и подготовки данных для обучения
