# Communication Service — Обзор

## Назначение

Сервис коммуникации отвечает за надёжную и масштабируемую передачу сообщений между облаком и роботами, а также внутри системы между микросервисами. Включает MQTT-брокер для роботов, RabbitMQ для внутренней асинхронной передачи и вспомогательные компоненты для маршрутизации и контроля качества обслуживания.

---

## Компоненты

- MQTT Broker (EMQX) — взаимодействие с роботами по MQTT
- RabbitMQ — внутренние очереди, задачи Celery
- Router/Bridge — мосты между MQTT и RabbitMQ для маршрутизации сообщений
- Topic Manager — шаблоны топиков и политика доступа
- Monitoring & ACL — мониторинг, аудит и контроль доступа

---

## Требования

- Низкая латентность для критических сообщений
- Гарантированная доставка для команд (QoS 1/2)
- Масштабируемость и мульти-тенантность
- Механизмы LWT, Retained messages и Offline queues
