# Топики и маршрутизация сообщений

## Стратегия топиков MQTT

- Формат: `agentswarm/{tenant}/{robot_id}/{component}/{channel}`
- Примеры:
  - `agentswarm/companyA/robot_001/camera/image_meta`
  - `agentswarm/companyA/robot_001/cmd/exec`
  - `agentswarm/companyA/robot_001/telemetry/pose`

---

## Правила маршрутизации

- Малые payloads (телеметрия, состояние) передаются прямо по MQTT
- Большие данные (кадры) передаются через MinIO: в MQTT отправляется ссылка + метаданные
- Bridge переводит MQTT-сообщения в RabbitMQ для дальнейшей внутренней обработки, если нужно

---

## QoS и LWT

- QoS выбирается по семантике топика (см. MQTT-брокер)
- LWT содержит код состояния робота и последний known location

---

## ACL и безопасность

- Каждый робот имеет ключ/сертификат; ACL ограничивает список разрешённых топиков
- Административные команды имеют отдельный namespace и повышенные требования по аутентификации
