# Frontend — Обзор

## Назначение

Frontend предоставляет пользовательский интерфейс для управления роем, мониторинга состояния роботов, визуализации карт и взаимодействия через чат. Основная цель — интуитивная панель управления для операторов и разработчиков.

---

## Компоненты

- Dashboard (React)
- WebSocket/REST клиент для получения реального времени
- 3D-визуализация (Three.js)
- Chat Interface с поддержкой streaming ответов от vLLM
- Утилиты для создания и контроля задач

---

## Требования UX

- Минимальная задержка обновления состояния (реальное время)
- Чёткая визуализация зон и траекторий
- Контроль доступа и многоуровневые разрешения
