# 3D Визуализация

## Назначение

3D-визуализация даёт оператору пространственное представление о роевом поведении: положения роботов, траектории, обнаруженные объекты, зоны и препятствия.

---

## Технологии

- Three.js / react-three-fiber
- WebGL для рендеринга большого числа объектов
- Level-of-Detail для оптимизации при большом количестве роботов

---

## Данные и обновления

- Получение состояния через WebSocket (пакеты с позицией, ориентацией, треками)
- Интерполяция траекторий для плавного отображения при нестабильной связи
- Визуализация детекций и масок (overlay)

---

## UX

- Панель слоёв: включение/отключение треков, масок, зон
- Таймлайн воспроизведения: просмотр исторических данных
