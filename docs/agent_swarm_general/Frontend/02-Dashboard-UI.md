# Dashboard UI

## Цель

Интерфейс для мониторинга состояния роя, распределения задач, просмотра телеметрии и управления зонами.

---

## Основные виджеты

- Список роботов и их статус
- Карта/3D-сцена с позициями и траекториями
- События и логи в реальном времени
- Управление задачами и очередями
- Метрики производительности системы

---

## Взаимодействие

- Запросы к Gateway REST API для управления
- WebSocket для подписки на телеметрию и события

---

## Производительность

- Виртуализация списков, ленивый рендеринг
- Batch-обновления состояния для снижения нагрузки
