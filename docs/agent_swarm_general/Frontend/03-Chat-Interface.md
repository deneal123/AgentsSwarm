# Chat Interface

## Цель

Интерактивный чат для операторов и интеграция с vLLM и Orchestrator. Поддерживает потоковые ответы и tool-calling для выполнения команд через модель.

---

## Функциональные возможности

- Streaming ответов (SSE / WebSocket)
- История диалога с привязкой к событиям и кадрам
- Кнопки быстрого действия (создать задачу, отправить команда роботу)
- Визуальное подтверждение выполнения команд

---

## Безопасность и подтверждения

- Для критичных команд требуется подтверждение оператора
- Логи чата связаны с audit logs в PostgreSQL

---

## UX рекомендации

- Показывать intermediate partial outputs
- Подсветка сущностей (робот, зона, объект) при наведении
